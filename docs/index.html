#1 Aktivní zneužívání zero-day zranitelností v N-able N-central

🎯 Cíl: N-able N-central (RMM platforma pro správu IT infrastruktury).

⚡ Podstata: Platforma N-able N-central čelí sérii kritických zero-day zranitelností, které umožňují neautentizované RCE a eskalaci privilegií až na úroveň root/SYSTEM.

🌍 Co to znamená pro běžné lidi: Útočníci mohou převzít plnou kontrolu nad servery, které spravují firemní počítače. Pokud vaše IT oddělení používá N-central, je nutné okamžitě aplikovat bezpečnostní záplaty.

Rozbalit přeložený článek a technický rozbor

📄 Překlad článku

Společnost N-able vydala opravy pro kritické zero-day zranitelnosti v platformě N-central, které byly zveřejněny výzkumníkem Seanem Balesem. Útočníci začali tyto zranitelnosti aktivně zneužívat k průzkumu a pokusům o kompromitaci systémů. Zranitelnosti zahrnují XXE, OGNL Injection, RCE prostřednictvím path traversal a eskalaci privilegií. N-able musela dočasně odstavit cloudové instance a vyzvala on-premise zákazníky k okamžitému odpojení serverů. Nové exploity (4EverAble2Shell a Agent2Shell) navíc zneužívají zranitelnost Apache Axis (CVE-2026-90436) k dosažení root přístupu.

⚙️ Jak to funguje

Útočníci využívají řetězec zranitelností (chaining), kde XXE (XML External Entity) vede k RCE. Zneužitím neautentizovaných IPC kanálů a path traversal v nahrávání souborů získávají útočníci možnost spouštět kód s právy uživatele 'nable' nebo 'root'. Následná eskalace probíhá přes zneužití konfigurace syslog-ng nebo zranitelnosti v Apache Axis.

🛡️ Mitigace

  • Aktualizace na verzi N-central 2026.4 HF2.
  • Okamžité zakázání Legacy API.
  • Audit autentizačních logů a záznamů o instalaci rozšíření.

🎯 MITRE ATT&CK

  • T1190
  • T1068
  • T1203
  • T1059

Skóre: +3 In the wild, +2 Remote exploit bez autentizace, +2 Enterprise software, +1 PoC exploit, +1 Privilege Escalation, +1 Chybí patch (původní zero-day)

📖 Slovníček pojmů

RCE: Remote Code Execution – schopnost útočníka vzdáleně spustit libovolný kód na cílovém systému.
XXE: XML External Entity – zranitelnost umožňující útočníkovi číst soubory na serveru nebo provádět SSRF útoky skrze zpracování XML dat.
OGNL Injection: Vstřikování kódu do objektově orientovaného jazyka (Object-Graph Navigation Language), často používaného v Java aplikacích.
Path Traversal: Technika umožňující útočníkovi přistupovat k souborům mimo zamýšlený adresář aplikace.

#2 Aktivní zneužívání Cisco BroadWorks prostřednictvím autonomního AI agenta

🎯 Cíl: Cisco BroadWorks (telekomunikační platforma).

⚡ Podstata: Zranitelnost v Cisco BroadWorks (XXE) je zneužívána autonomním AI agentem k exfiltraci citlivých dat a systémových klíčů.

🌍 Co to znamená pro běžné lidi: Útočníci využívají pokročilé AI k automatizovanému napadení telekomunikačních systémů. Pro firmy to znamená riziko úniku citlivých dat a ztráty kontroly nad komunikací.

Rozbalit přeložený článek a technický rozbor

📄 Překlad článku

CISA zařadila zranitelnost CVE-2026-20320 v Cisco BroadWorks do katalogu aktivně zneužívaných hrozeb. Útočníci využívají autonomní framework postavený na upraveném modelu DeepSeek Flash k automatizovanému průzkumu a útoku. Agent dokáže bez autentizace číst libovolné soubory na serveru, čímž získal systémové identitní klíče a SSL certifikáty, což mu umožnilo impersonaci komponent platformy.

⚙️ Jak to funguje

Zranitelnost spočívá v nesprávném omezení XML External Entity (XXE) v OCI XML parseru. Útočník pošle speciálně vytvořenou XML zprávu na port 2208, což donutí parser číst soubory ze souborového systému serveru.

🛡️ Mitigace

  • Aplikace dostupných bezpečnostních záplat od Cisco.
  • Implementace risk-based vulnerability managementu dle doporučení CISA.

🎯 MITRE ATT&CK

  • T1190
  • T1552
  • T1068

Skóre: +3 In the wild, +2 Remote exploit bez autentizace, +2 Enterprise software, +1 PoC exploit, +1 Lateral Movement

📖 Slovníček pojmů

XXE: XML External Entity – zranitelnost umožňující útočníkovi číst soubory na serveru skrze zpracování XML dat.
OCI: Open Client Interface – rozhraní pro komunikaci s BroadWorks platformou.
