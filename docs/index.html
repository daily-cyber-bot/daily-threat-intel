#1 Kritická zranitelnost v ScreenConnect zneužívána k šíření SCKit malwaru

🎯 Cíl: Enterprise systémy pro vzdálenou správu (RMM) ScreenConnect.

⚡ Podstata: Útočníci zneužívají kritickou zranitelnost v nástroji ScreenConnect k instalaci malwaru SCKit, který umožňuje vzdálené ovládání a šíření v síti.

🌍 Co to znamená pro běžné lidi: Útočníci mohou převzít kontrolu nad počítači, které používají technici pro vzdálenou podporu. Pokud používáte tento software, okamžitě jej aktualizujte na verzi 26.6.5 nebo novější.

Rozbalit přeložený článek a technický rozbor

📄 Překlad článku

Společnost ConnectWise dokončila vyšetřování neoprávněných přístupů do prostředí ScreenConnect a doporučuje uživatelům aktualizaci na verzi 26.6.5. Útočníci zneužívají zranitelnost CVE-2026-84869 (CVSS 9.9), která umožňuje přenos a spuštění souborů bez autorizace. Útoky využívají toolkit SCKit, který se šíří jako červ z infikovaných zařízení na pracovní stanice techniků. Malware využívá modul RelayTrap.cs pro laterální pohyb v síti. ConnectWise preventivně zakázala pět rizikových rozšíření třetích stran.

⚙️ Jak to funguje

Zranitelnost umožňuje obejití autentizačních kontrol v RMM+ verzích 1.0.31 a 1.0.32. Útočník využije chybu v přenosu souborů k injektáži kódu do paměti procesu technika, čímž získá oprávnění SYSTEM a možnost instalovat perzistentní backdoor (např. maskovaný jako Windows Update Agent).

🛡️ Mitigace

  • Aktualizace ScreenConnect na verzi 26.6.5+
  • Zakázání rizikových rozšíření (Labtech Plus, RMM Plus atd.)
  • Revize logů na přítomnost procesu UpdateConnect.ClientService.exe

Skóre: +3 In the wild, +2 Remote exploit bez autentizace, +2 Dopad na enterprise software, +1 Veřejný PoC exploit, +1 Privilege Escalation, +1 Chybí patch (pro neaktualizované systémy)

📖 Slovníček pojmů

RMM: Remote Monitoring and Management – nástroje pro vzdálenou správu a monitoring IT infrastruktury.
SCKit: Toolkit používaný útočníky pro automatizované šíření malwaru v rámci kompromitovaných RMM sítí.
CVSS: Common Vulnerability Scoring System – standard pro hodnocení závažnosti zranitelností.

#2 Masivní zneužití zranitelností v N-central k těžbě kryptoměn

🎯 Cíl: N-able N-central (RMM/UEM platforma).

⚡ Podstata: Útočníci zneužívají řadu zranitelností v platformě N-central k získání SYSTEM oprávnění a instalaci těžařů kryptoměn.

🌍 Co to znamená pro běžné lidi: Pokud vaše firma používá N-central, servery mohou být zneužity k nelegální těžbě kryptoměn, což zpomaluje systémy a ohrožuje bezpečnost dat. Je nutná okamžitá aktualizace.

Rozbalit přeložený článek a technický rozbor

📄 Překlad článku

Společnost N-able vydala kritickou aktualizaci N-central 2026.4 Hotfix 3, která opravuje 17 zranitelností. Tyto chyby umožňují útočníkům obejít autentizaci, provádět path traversal, injektovat XML entity a získat SYSTEM oprávnění. Útočníci aktivně zneužívají tyto vektory (označované jako 4EverAble2Shell a Agent2Shell) k nasazení těžařů kryptoměn. Aktualizace zcela odstraňuje podporu pro legacy API, která byla hlavním vektorem útoku.

⚙️ Jak to funguje

Zranitelnosti umožňují řetězení útoků od neautentizovaného přístupu přes API až po RCE (Remote Code Execution) pod účtem SYSTEM. Útočníci využívají chyby v parsování XML a nedostatečnou validaci vstupů v serverových komponentách k eskalaci privilegií.

🛡️ Mitigace

  • Upgrade na N-central 2026.4 Hotfix 3
  • Aktualizace všech Agentů a Prob
  • Odstranění legacy API konfigurací

🎯 MITRE ATT&CK

  • T1068
  • T1496
  • T1190

Skóre: +3 In the wild, +2 Remote exploit bez autentizace, +2 Dopad na enterprise software, +1 Privilege Escalation, +1 Chybí patch (pro neaktualizované systémy)

📖 Slovníček pojmů

RCE: Remote Code Execution – schopnost útočníka vzdáleně spustit libovolný kód na cílovém systému.
Path Traversal: Zranitelnost umožňující přístup k souborům mimo zamýšlený adresářový strom.
